# TestJusticia — Tramitación Procesal y Administrativa

Aplicación web progresiva (PWA) de test para preparar la oposición al Cuerpo de
Tramitación Procesal y Administrativa (Justicia, Andalucía).

## Qué incluye

- **Exámenes oficiales completos** descargados de los cuadernillos publicados por el
  Ministerio de Justicia (2020, 2024 y 2025, con sus plantillas de respuestas).
- **Configurador de test**: número de preguntas, tiempo, modo examen o estudio,
  origen (oficiales / material del preparador) y conjunto (todas, sin contestar,
  falladas o muy falladas).
- **Estadística por pregunta**: recuento de aciertos y fallos de cada pregunta del
  pool, que se conserva entre sesiones.
- **Justificación y base legal** cuando están verificadas contra el BOE; las que no
  lo están quedan marcadas como pendientes (nunca se inventa una respuesta).

## Uso

Abre el enlace, y desde el navegador del móvil usa "Añadir a pantalla de inicio"
para instalarla. Funciona sin conexión una vez cargada.

## Aviso

Las preguntas proceden de los cuadernillos oficiales publicados por el Ministerio
de Justicia (documentos públicos). Las justificaciones y la aplicación son propias.
