# TestJusticia — Tramitación Procesal y Administrativa

PWA de tests y simulacros para preparar la oposición de **Tramitación Procesal y
Administrativa** (Justicia, Andalucía), con preguntas de **exámenes oficiales**.

## Uso

- Abrir el enlace en el navegador del móvil u ordenador.
- En el móvil: menú del navegador -> **"Añadir a pantalla de inicio"** para
  instalarla como aplicación (funciona sin conexión).

## Contenido

- **Exámenes oficiales enteros**: modelos A/B, exámenes de incidencias y de
  promoción interna, tal como se publicaron.
- **Configurador de test**: número de preguntas, tiempo, modo examen o estudio,
  fuente (oficiales / preparador) y conjunto (todas, sin contestar, falladas,
  muy falladas).
- **Recuento por pregunta**: aciertos, fallos y blancas de cada pregunta, que se
  conserva en el navegador.

## Aviso

Las preguntas proceden de los cuadernillos publicados por el Ministerio de
Justicia (documentos públicos). No se copia ningún banco de pago.
